# 음원

Suno 는 음원을 암호화해 내보내서 외부 사이트에서 바로 스트리밍할 수 없다.
Suno 에서 **Download → MP3** 로 받은 파일을 아래 이름으로 `public/audio/creative/` 에 넣는다.
(파일명은 Suno 클립 id. 곡 정보는 `src/data/creative.ts`, 경로 베이스는 거기의 `AUDIO_BASE`.)

mp3 는 저장소에 올리지 않는다 (`.gitignore`). 배포 서버나 R2 에 따로 올리고, R2 를 쓰면 `AUDIO_BASE` 를 그 URL 로 바꾼다.
